# Function Reference

Signatures, parameter defaults, compile-time type/shape rules, argument omission (`_`), conditional aggregation and debt amortization patterns, and domain error modes for the 37 built-in Excel functions in `f8`.

---

## 1. Call Rules, Compile-Time Validation, Argument Omission, and Error Semantics

- Calculation parity: IEEE 754 `f64` arithmetic (`-0.0` normalized to `0.0`, non-finite overflow mapped to `#NUM!`), strict compile-time type/shape verification, and Excel domain error propagation. Excludes dynamic array spilling (`#SPILL!`), implicit intersection, wildcards, and volatile functions (`TODAY()`, `RAND()`).
- Two-stage compile-time validation (throws `F8Error` during `model.compile()` Pass 4 before `.xlsx` emission, covering static type/shape/role checks across both active and untaken lazy branches in `IF`, `IFERROR`, `CHOOSE`, and `XLOOKUP`, and runtime `Empty` checks on executed paths):
  - Signature & omission rules: Unknown function name (`UnknownFunction`), arity bounds (`TooFewArguments`, `TooManyArguments`), and `_` omission (`CannotOmitRequiredArgument` checked before `CannotOmitTrailingArgument`).
  - Scalar, logical, relational, and `Empty` rules: Unary `-`, binary arithmetic, and numeric scalar parameters require `Number` (rejecting `Text`, `Boolean`, and `Empty` via `InvalidOperandType`, `InvalidArgumentType`, `EmptyOperand`, or `EmptyArgument`); logical conditions (`IF`, `NOT`, and non-slice `AND`/`OR` arguments including `1x1` single-cell references) require `Boolean`; relational operators (`=`, `<>`, `<`, `<=`, `>`, `>=`) require non-`Empty` operands (`EmptyOperand`) of identical type (`IncompatibleComparison`); formula cells evaluating to `Empty` at the cell root fail with `EmptyFormulaResult` (`"formula cannot evaluate to an empty cell"`).
  - Numeric/financial aggregation role & `Empty` rules: `SUM`, `AVERAGE`, `MIN`, `MAX`, `MEDIAN`, `COUNT`, `SUMPRODUCT`, `NPV`, `IRR`, `XNPV`, and `XIRR` reject `descriptor` column references (`DescriptorReferenceNotAllowed`), `Text` and `Boolean` values anywhere (`InvalidArgumentType`), and `Empty` on scalar or `1x1` single-cell references (`EmptyArgument`). `NPV`, `IRR`, `XNPV`, and `XIRR` (`EmptyPolicy::Forbid`) also reject `Empty` cells inside `start..end` slices (`EmptyArgument`; missing cash flows must be explicit `0.0`), while math and logical aggregations (`EmptyPolicy::AllowInSlice`) skip sparse `Empty` cells inside syntactic `start..end` slices (`0.0` in `SUM`/`SUMPRODUCT`).
  - Monomorphic branches & static `ValueType` inference: Result arms in `IF` (all 3 arguments required), `CHOOSE`, `IFERROR`, and `XLOOKUP` (`return_array` + `if_not_found`) must unify to a single scalar type (`IncompatibleBranchTypes`) and evaluate to non-`Empty` scalars when selected (`EmptyArgument`). `NA()` acts as polymorphic bottom (`#N/A`) for dynamic non-meaningful ratios, while formulas that evaluate to runtime `ExcelError` preserve their static `ValueType` across cell references and range slices.
  - Range-only slots, slice geometry, and lookup invariants: Syntactic `start..end` slices in scalar contexts fail with `SliceInScalarContext`; range-only slots (`COUNT`, `SUMPRODUCT`, `XLOOKUP`/`XMATCH`/`INDEX` arrays, `IRR`/`XNPV`/`XIRR` series) require `Table[...]` references (`InvalidArgumentKind`); mismatched range dimensions/lengths (`SUMPRODUCT`, `XLOOKUP`, `XNPV`, `XIRR` -> `DimensionMismatch` / `LengthMismatch`), 2D matrices in 1D slots (`XLOOKUP`, `XMATCH`, `XNPV`, `XIRR` -> `ExpectedOneDimensionalSlice`), omitted `col_num` on 2D `INDEX` (`MissingColumnIndexFor2DSlice`), heterogeneous `lookup_array`/`return_array`/`INDEX` slices (`InvalidArgumentType`), and `Empty` `lookup_value`, `1x1` single-cell `Empty` lookup/index arrays, or selected `Empty` elements in `XLOOKUP`/`INDEX` (`EmptyArgument`) fail compilation with `F8Error`.
- Argument omission (`_`):
  - Intermediate optional positional parameters can be skipped via `_` when followed by at least one explicit argument (`PMT(rate, nper, pv, _, 1)`, `XLOOKUP(k, look, ret, _, -1)`, `XLOOKUP(k, look, ret, _, _, -1)`). Omitting a required parameter (`ABS(_)`, `IF(cond, t, _)`) or trailing optional parameter (`PMT(r, n, pv, _)`, `YEARFRAC(s, e, _)`) with `_` fails at compile time (`CannotOmitRequiredArgument` / `CannotOmitTrailingArgument`); omit trailing optional arguments directly (`PMT(r, n, pv)`, `YEARFRAC(s, e)`).
  - Intermediate `_` slots bind to their declared default value (or `FunctionArg::Omitted` for `XLOOKUP`'s lazy `if_not_found`, returning `#N/A` on miss); absent trailing optional arguments are not synthetically padded.
  - In lowered Excel formulas, intermediate `_` emits an empty positional argument (`=PMT(C5,C6,C7,,1)`, `=XLOOKUP(..., ..., ..., , , -1)`).
- Runtime Excel error values (returned as cell values and propagated through dependent formulas):
  - `#DIV/0!`: `x / 0`, `0 ^ -k`, `MOD(number, 0)`, `AVERAGE` on an all-empty slice, or `r = -1.0` in `NPV`.
  - `#VALUE!`: Out-of-bounds `index_num < 1` or `> N` in `CHOOSE`, zero `Boolean` values across sparse `AND`/`OR` range slices, unsupported `match_mode` (outside `{0, -1, 1}`, including wildcard `2`) or `search_mode` (outside `{1, -1, 2, -2}`) in `XLOOKUP`/`XMATCH`, or `Empty` / unsorted `lookup_array` under binary search (`search_mode = 2` or `-2`; `Error` cells inside binary-search `lookup_array`s bubble their `ExcelError`).
  - `#REF!`: Out-of-bounds `row_num` or `col_num` (`< 1` or exceeding slice dimensions) in `INDEX`.
  - `#NUM!`: Negative base with fractional exponent (`(-2) ^ 0.5`), `0 ^ 0`, `LN(number <= 0)`, `EXP` overflow (`> ~709.78`), `MOD` with `|number / divisor| > 2^53 - 1` or non-finite quotient, `NaN`/`Inf` overflow, non-integer numeric arguments at discrete integer parameters (`ROUND`/`ROUNDUP`/`ROUNDDOWN` `num_digits`, `CHOOSE` `index_num`, `INDEX` `row_num`/`col_num`, `XLOOKUP`/`XMATCH` `match_mode`/`search_mode`, `DATE` `year`/`month`/`day`, `EDATE`/`EOMONTH` `months`, `YEARFRAC` `basis`, `PMT` `type`), `DATE(year, month, day)` outside `1900..=9999` / `1..=12` / `1..=days_in_month` (preserving `1900-02-29` -> `60.0` while rejecting 2-digit years and rollovers), input date serials outside `1.0..=2958465.0` (including `0` = `1900-01-00`) across `YEAR`/`MONTH`/`DAY`/`EDATE`/`EOMONTH`/`YEARFRAC` and `XNPV`/`XIRR` `dates`, `PMT` `type` outside `{0, 1}`, `YEARFRAC` `basis` outside `0..=4`, `MEDIAN` on an all-empty slice, `IRR`/`XIRR` with `guess <= -1.0`, `< 2` cash flows, missing sign alternation, or non-convergence, `XNPV` with `rate <= 0.0`, dates preceding the initial date (`trunc(d_i) < trunc(d_1)`) in `XNPV`/`XIRR`, `rate <= -1.0` or `nper = 0` in `PMT`, or `EDATE`/`EOMONTH` stepping a valid `start_date` outside `1900..=9999`.
  - `#N/A`: `NA()` or unmatched lookup in `XLOOKUP` (without `if_not_found`) or `XMATCH`.

| `AVERAGE`    | `AVERAGE(number1, [number2], ...)`  | Arithmetic mean across `Number` scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` throw `F8Error`; sparse `Empty` cells in `start..end` slices are skipped; returns `#DIV/0!` on all-empty slices).                                         |
| `COUNT`      | `COUNT(value1, [value2], ...)`      | Counts `Number` cells across `Table[...]` `measure` references (`descriptor` columns, `Text`, `Boolean`, and `1x1` `Empty` throw `F8Error`; ignores sparse `Empty` cells in `start..end` slices and runtime `Error` cells).                                                                                                  |
| `MAX`        | `MAX(number1, [number2], ...)`      | Maximum `Number` across scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` throw `F8Error`; sparse `Empty` cells in `start..end` slices are skipped, returning `0.0` on all-empty slices).                                                   |
| `MIN`        | `MIN(number1, [number2], ...)`      | Minimum `Number` across scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` throw `F8Error`; sparse `Empty` cells in `start..end` slices are skipped, returning `0.0` on all-empty slices).                                                   |
| `MEDIAN`     | `MEDIAN(number1, [number2], ...)`   | Median of `Number` inputs across scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` throw `F8Error`; sparse `Empty` cells in `start..end` slices are skipped, averaging middle two on even count and returning `#NUM!` on all-empty slices). |
| `ROUND`      | `ROUND(number, num_digits)`         | Base-10 15-significant-digit commercial rounding (half-away-from-zero) of `Number` `number` to integer `num_digits` decimal places (negative `num_digits` rounds left of decimal point; float overflow or non-integer `num_digits` returns `#NUM!`).                                                                         |
| `ROUNDUP`    | `ROUNDUP(number, num_digits)`       | Base-10 15-significant-digit rounding of `Number` `number` away from zero to integer `num_digits` decimal places (float overflow or non-integer `num_digits` returns `#NUM!`).                                                                                                                                               |
| `ROUNDDOWN`  | `ROUNDDOWN(number, num_digits)`     | Base-10 15-significant-digit truncation of `Number` `number` toward zero to integer `num_digits` decimal places (non-integer `num_digits` returns `#NUM!`).                                                                                                                                                                  |
| `SUMPRODUCT` | `SUMPRODUCT(array1, [array2], ...)` | Element-wise product and sum across equal-dimension 1D/2D `Table[...]` `measure` ranges (`descriptor` columns, non-reference scalars, mismatched dimensions, `Text`, `Boolean`, and `1x1` `Empty` throw `F8Error`; sparse `Empty` cells in `start..end` slices contribute `0.0`; float overflow returns `#NUM!`).            |

### Conditional Aggregation Composition

`COUNTA`, `SUMIFS`, `COUNTIFS`, `AVERAGEIFS`, `MINIFS`, and `MAXIFS` are intentionally omitted (`UnknownFunction`). Compose conditional aggregations explicitly with helper/flag rows or columns:

- Conditional sum: Define a helper row/column `IF(cond, value, 0)` and aggregate with `SUM(...)`, or define a `0`/`1` flag row/column `IF(cond, 1, 0)` and aggregate with `SUMPRODUCT(values, flags)`.
- Conditional count: Define a `0`/`1` flag row/column `IF(cond, 1, 0)` (combining multiple conditions via `AND(...)` / `OR(...)`) and aggregate with `SUM(flags)`.
- Conditional average: Combine finite `values` and `0`/`1` `flags` via `SUMPRODUCT(values, flags) / SUM(flags)`, or `SUM(zeroed_helper) / SUM(flags)` when excluded cells evaluate to `NA()` (`SUMPRODUCT` propagates `#N/A` even against a `0` flag; guard `SUM(flags) = 0` with `IF` if needed).
- Outlier-excluded `MIN` / `MAX` / `AVERAGE` / `MEDIAN`: `MIN`, `MAX`, `AVERAGE`, and `MEDIAN` skip `Empty` (`null`) cells inside `start..end` range slices—use 0D `null` overrides on excluded cells in a helper row/column when computing static subset extrema.

## 3. Logical and Branching Functions (6)

| :-------- | :------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `IF`      | `IF(logical_test, value_if_true, value_if_false)` | Short-circuiting 3-argument branch (`TooFewArguments` if `value_if_false` is omitted). `logical_test` requires `Boolean`; `value_if_true` and `value_if_false` must unify to a single scalar type (`NA()` allowed for dynamic `#N/A` suppression; evaluated arms resolving to `Empty` throw `F8Error` `EmptyArgument`).    |
| `IFERROR` | `IFERROR(value, value_if_error)`                  | Short-circuiting error trap: returns `value_if_error` only if `value` evaluates to a runtime Excel error (compile-time `F8Error`s propagate without trapping; both arms must be non-`Empty` and unify to a single scalar type).                                                                                            |
| `AND`     | `AND(logical1, [logical2], ...)`                  | Logical conjunction across `Boolean` scalars, single-cell references, and range slices. `Number` and `Text` anywhere, and `Empty` on scalars or `1x1` single-cell references, throw `F8Error`; sparse `Empty` cells inside syntactic `start..end` slices are skipped, returning `#VALUE!` if zero `Boolean` inputs remain. |
| `OR`      | `OR(logical1, [logical2], ...)`                   | Logical disjunction across `Boolean` scalars, single-cell references, and range slices. `Number` and `Text` anywhere, and `Empty` on scalars or `1x1` single-cell references, throw `F8Error`; sparse `Empty` cells inside syntactic `start..end` slices are skipped, returning `#VALUE!` if zero `Boolean` inputs remain. |
| `NOT`     | `NOT(logical)`                                    | Logical negation of a `Boolean` scalar (`NOT(TRUE)` -> `FALSE`, `NOT(FALSE)` -> `TRUE`; `Number`, `Text`, and `Empty` throw `F8Error`).                                                                                                                                                                                    |
| `CHOOSE`  | `CHOOSE(index_num, value1, [value2], ...)`        | Evaluates and returns choice at 1-based integer `index_num` with short-circuiting (all choice arms must unify to a single scalar type; selected arm resolving to `Empty` throws `F8Error` `EmptyArgument`). Non-integer `index_num` returns `#NUM!`; out-of-bounds `index_num` (`< 1` or `> N`) returns `#VALUE!`.         |

## 4. Financial and Discounting Functions (5)

| Function | Signature                           | Semantics                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| :------- | :---------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NPV`    | `NPV(rate, value1, [value2], ...)`  | Periodic net present value starting at `t = 1` (`rate` requires `Number`; `value1..` require `Number` scalars or `measure` references with no `Empty`, `Text`, or `Boolean` cells—missing periodic cash flows must be explicit `0.0`, else `F8Error`): `sum(CF_t / (1 + rate)^t)`. Returns `#DIV/0!` if `rate = -1.0`; `rate < -1.0` is allowed (integer exponents); float overflow returns `#NUM!`.                                                                                                                                           |
| `XNPV`   | `XNPV(rate, values, dates)`         | Exact-date net present value using Actual/365 (`rate` requires `Number`; `values` and `dates` require equal-length 1D `Table[...]` `measure` ranges of `Number` cells with no `Empty`, `Text`, or `Boolean` cells, else `F8Error`): `sum(CF_i / (1 + rate)^((d_i - d_1) / 365))`. Requires `rate > 0.0` (matching Excel's legacy `XNPV` quirk rejecting non-positive discount rates with `#NUM!` even when `-1.0 < rate <= 0.0`), valid date serials `1.0..=2958465.0` in `dates`, and `trunc(d_i) >= trunc(d_1)` (violations return `#NUM!`). |
| `IRR`    | `IRR(values, [guess])`              | Periodic internal rate of return via safeguarded Newton-Brent root-finding (`values` requires `Table[...]` `measure` range of `Number` cells with no `Empty`, `Text`, or `Boolean` cells, else `F8Error`; `guess` requires `Number`, default `0.10`). Returns `#NUM!` if `guess <= -1.0`, `< 2` cash flows, no sign alternation, or no real root `> -1.0`.                                                                                                                                                                                     |
| `XIRR`   | `XIRR(values, dates, [guess])`      | Exact-date internal rate of return using Actual/365 via safeguarded Newton-Brent root-finding (`values` and `dates` require equal-length 1D `Table[...]` `measure` ranges of `Number` cells with no `Empty`, `Text`, or `Boolean` cells, else `F8Error`; `guess` requires `Number`, default `0.10`). Returns `#NUM!` if `guess <= -1.0`, `< 2` cash flows, any date serial is outside `1.0..=2958465.0`, `trunc(d_i) < trunc(d_1)`, no net sign alternation across distinct dates, or no real root `> -1.0`.                                   |
| `PMT`    | `PMT(rate, nper, pv, [fv], [type])` | Constant annuity payment (`rate`, `nper`, `pv`, `fv` require `Number`, `fv` default `0.0`; `type` requires integer in `{0, 1}`, default `0` for end-of-period, `1` for beginning-of-period; non-integer or other values return `#NUM!`). Supports `rate = 0.0`; returns `#NUM!` if `rate <= -1.0` or `nper = 0.0`.                                                                                                                                                                                                                             |

### Debt Amortization Composition

`IPMT` and `PPMT` are intentionally omitted (`UnknownFunction`). Compose period-by-period interest and principal explicitly with `PMT` and a 2D corkscrew schedule:

- Level debt service payment: Compute constant periodic payment with `PMT(rate, nper, -opening_principal)`.
- Period interest and principal (corkscrew): Track `opening_balance` (`col.prev` `closing_balance`), compute `interest = opening_balance * rate`, `principal = scheduled_pmt - interest` (or `MIN(opening_balance, scheduled_pmt - interest)`), and `closing_balance = opening_balance - principal`.

## 5. Lookup and Reference Functions (3)

| Function  | Signature                                                                                        | Semantics                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| :-------- | :----------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `XLOOKUP` | `XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])` | Searches homogeneous 1D `lookup_array` (`Table[...]` required) for non-`Empty` `lookup_value` of matching type and returns corresponding element from equal-length homogeneous 1D `return_array` (monomorphic with lazy `if_not_found`; unselected `Empty` cells in syntactic `start..end` slices are skipped, while `1x1` single-cell `Empty` arrays or selecting an `Empty` `return_array` element / `if_not_found` arm throws `F8Error` `EmptyArgument`). Default `match_mode = 0`, `search_mode = 1`. Unmatched lookup returns `if_not_found` or `#N/A` if omitted; 2D slices, length mismatches, `Empty` `lookup_value`, or heterogeneous arrays throw `F8Error`. |
| `XMATCH`  | `XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])`                                | Returns 1-based index of non-`Empty` `lookup_value` in homogeneous 1D `lookup_array` (default `match_mode = 0`, `search_mode = 1`; unselected `Empty` cells in syntactic `start..end` slices are skipped in linear search, while `1x1` single-cell `Empty` `lookup_array` throws `F8Error` `EmptyArgument`). Returns `#N/A` if unmatched; 2D slices, `Empty` `lookup_value`, or heterogeneous keys throw `F8Error`.                                                                                                                                                                                                                                                    |
| `INDEX`   | `INDEX(array, row_num, [col_num])`                                                               | Returns element at 1-based integer `row_num` and `col_num` within a homogeneous 1D or 2D `Table[...]` range (`1x1` single-cell `Empty` `array` or selecting an `Empty` element throws `F8Error` `EmptyArgument`). On 1D vectors, omitting `col_num` (or passing `1`) indexes along the vector axis; on 2D matrices, `col_num` is required (`MissingColumnIndexFor2DSlice`). Non-integer indices return `#NUM!`; out-of-bounds indices return `#REF!`.                                                                                                                                                                                                                  |

### `match_mode` and `search_mode` (`XLOOKUP`, `XMATCH`)

- Mode values: Both `match_mode` and `search_mode` require `Number` (non-integer values return `#NUM!`; unsupported integer mode codes return `#VALUE!`).
- `match_mode`: `0` (default) = exact match (ASCII case-insensitive for text); `-1` = exact or next smaller; `1` = exact or next larger (wildcard `match_mode = 2` is not supported and returns `#VALUE!`).
- `search_mode`: `1` (default) = first-to-last; `-1` = last-to-first; `2` = binary search ascending (first exact match on duplicates); `-2` = binary search descending (last exact match on duplicates). Binary search modes (`2`, `-2`) require every `lookup_array` cell to be non-`Empty`, non-`Error`, and monotonically sorted (`#VALUE!` on `Empty` or unsorted keys; `Error` cells bubble their `ExcelError`).

## 6. Date and Time Functions (7)

| Function   | Signature                                 | Semantics                                                                                                                                                                                                                                                                                                                                                                           |
| :--------- | :---------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATE`     | `DATE(year, month, day)`                  | Constructs Excel serial date (`1.0 <= serial <= 2958465.0`, corresponding to `1900-01-01`..`9999-12-31`) from valid calendar integer `year` (`1900..=9999`), `month` (`1..=12`), and `day` (`1..=days_in_month`, preserving Excel's 1900 leap-year bug `1900-02-29` -> `60.0`; non-integers, 2-digit years `0..=1899`, out-of-range years, and month/day rollovers return `#NUM!`). |
| `EDATE`    | `EDATE(start_date, months)`               | Shifts `start_date` (`1.0..=2958465.0`, else `#NUM!`) by integer `months` calendar months (non-integer `months` returns `#NUM!`), clamping end-of-month overflow to the final valid Gregorian day of the target month (`1900-02` clamps to `1900-02-28` -> `59.0`; stepping outside `1900..=9999` returns `#NUM!`).                                                                 |
| `EOMONTH`  | `EOMONTH(start_date, months)`             | Returns serial date for the last Gregorian day of the month integer `months` before or after `start_date` (`1.0..=2958465.0`, else `#NUM!`; `1900-02` returns `1900-02-28` -> `59.0`; non-integer `months` or stepping outside `1900..=9999` returns `#NUM!`).                                                                                                                      |
| `YEARFRAC` | `YEARFRAC(start_date, end_date, [basis])` | Year fraction between `start_date` and `end_date` (`1.0..=2958465.0`, order-independent; truncates fractional time). Default integer `basis = 0` in `0..=4` (non-integer `basis`, `basis` outside `0..=4`, or serial outside `1.0..=2958465.0` returns `#NUM!`).                                                                                                                    |
| `YEAR`     | `YEAR(serial_number)`                     | Extracts 4-digit year (`1900..=9999`) from `serial_number` (`1.0..=2958465.0`, rejecting `0` = `1900-01-00` and out-of-range serials with `#NUM!`).                                                                                                                                                                                                                                 |
| `MONTH`    | `MONTH(serial_number)`                    | Extracts month (`1..=12`) from `serial_number` (`1.0..=2958465.0`, rejecting `0` and out-of-range serials with `#NUM!`).                                                                                                                                                                                                                                                            |
| `DAY`      | `DAY(serial_number)`                      | Extracts day of month (`1..=31`) from `serial_number` (`1.0..=2958465.0`, rejecting `0` and out-of-range serials with `#NUM!`).                                                                                                                                                                                                                                                     |

### `YEARFRAC` Day-Count Basis (`0..=4`)

| `basis`          | Convention          | Denominator / Day-Count Rule                                                                |
| :--------------- | :------------------ | :------------------------------------------------------------------------------------------ |
| `0` (or omitted) | US (NASD) 30/360    | 30-day months / 360-day year with US end-of-February and 31st-of-month adjustment rules     |
| `1`              | Actual/Actual (AFB) | Exact elapsed days divided by actual days in year (`365` or `366` based on leap-year rules) |
| `2`              | Actual/360          | Exact elapsed days divided by `360.0`                                                       |
| `3`              | Actual/365          | Exact elapsed days divided by `365.0`                                                       |
| `4`              | European 30/360     | 30-day months / 360-day year where any 31st day of month is clamped to `30`                 |

## 7. Information Functions (2)

| Function  | Signature        | Semantics                                                                                                                                                                                                                                                                     |
| :-------- | :--------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ISERROR` | `ISERROR(value)` | Returns `TRUE` if scalar `value` evaluates to any runtime Excel error (`#DIV/0!`, `#VALUE!`, `#REF!`, `#NAME?`, `#NUM!`, `#N/A`), and `FALSE` for `Number`, `Text`, and `Boolean` (`Empty` throws `F8Error` `EmptyArgument`; compile-time `F8Error`s still fail compilation). |
| `NA`      | `NA()`           | Returns `#N/A` with polymorphic bottom type, unifying with any typed branch arm (`IF(ebitda > 0, ev / ebitda, NA())`).                                                                                                                                                        |

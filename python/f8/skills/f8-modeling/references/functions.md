# Function Reference

Signatures, parameter defaults, compile-time type/shape rules, argument omission (`_`), conditional aggregation patterns, and domain error modes for the 43 built-in Excel functions in `f8`.

---

## 1. Call Rules, Compile-Time Validation, Argument Omission, and Error Semantics

- Calculation parity: IEEE 754 `f64` arithmetic (`-0.0` normalized to `0.0`, non-finite overflow mapped to `#NUM!`), strict compile-time type/shape verification, and Excel domain error propagation. Excludes dynamic array spilling (`#SPILL!`), implicit intersection, wildcards, and volatile functions (`TODAY()`, `RAND()`).
- Two-stage compile-time validation (raises `F8Error` during `model.compile()` Pass 4 before `.xlsx` emission, covering both active and untaken lazy branches in `IF`, `IFS`, `IFERROR`, `IFNA`, `CHOOSE`, and `XLOOKUP`):
  - Signature & omission rules: Unknown function name (`UnknownFunction`), arity bounds (`TooFewArguments`, `TooManyArguments`), pair-variadic counts (`IFS` -> `InvalidVariadicPairs`), and `_` omission (`CannotOmitRequiredArgument` checked before `CannotOmitTrailingArgument`).
  - Scalar, logical, relational, and root `Empty` rules: Unary `-`, binary arithmetic, and numeric scalar parameters require `Number` (rejecting `Text`, `Boolean`, and `Empty`); logical conditions (`IF`, `IFS`, `NOT`, and non-slice `AND`/`OR` arguments including `1x1` single-cell references) require `Boolean`; relational operators (`=`, `<>`, `<`, `<=`, `>`, `>=`) require non-`Empty` operands of identical type; formula cells evaluating to `Empty` at the cell root fail with `EmptyFormulaResult` (guard nullable cells via `ISBLANK(ref)`).
  - Parameter-boundary integer & domain rules: Discrete integer parameters (`ROUND`/`ROUNDUP`/`ROUNDDOWN` `num_digits`, `CHOOSE` `index_num`, `INDEX` `row_num`/`col_num`, `DATE` `year`/`month`/`day`, `EDATE`/`EOMONTH` `months`, `YEARFRAC` `basis`, and `PMT`/`IPMT`/`PPMT` `type`) enforce `Integer` strictly at the declaring parameter boundary across direct signed literals and active evaluated argument values (`NonIntegerArgument` on fractional floats or magnitudes exceeding `9007199254740991`); `DATE(year, month, day)` requires valid calendar dates with 4-digit `year` in `1900..=9999`, `month` in `1..=12`, and `day` in `1..=days_in_month` (`InvalidDateYear`, `InvalidDateMonth`, `InvalidDateDay`; `1900-02-29` -> `60.0` preserved, 2-digit years and rollovers rejected); `PMT`/`IPMT`/`PPMT` `type` requires `0` or `1` (`InvalidAnnuityType`); `YEARFRAC` `basis` requires `0..=4` (`InvalidDayCountBasis`); input date serials across `YEAR`/`MONTH`/`DAY`/`DAYS`/`EDATE`/`EOMONTH`/`YEARFRAC` and `XNPV`/`XIRR` `dates` require `1.0..=2958465.0` (`InvalidDateSerial`, rejecting `0` = `1900-01-00`).
  - Numeric/financial aggregation role & `Empty` rules: `SUM`, `AVERAGE`, `MIN`, `MAX`, `MEDIAN`, `COUNT`, `SUMPRODUCT`, `NPV`, `IRR`, `XNPV`, and `XIRR` reject `descriptor` column references (`DescriptorReferenceNotAllowed`), `Text` and `Boolean` values anywhere, and `Empty` on scalar or `1x1` single-cell references (`InvalidArgumentType`). `NPV`, `IRR`, `XNPV`, and `XIRR` also reject `Empty` cells inside `start..end` slices (missing cash flows must be explicit `0.0`), while math aggregations skip sparse `Empty` cells inside syntactic `start..end` slices (`0.0` in `SUM`/`SUMPRODUCT`).
  - Monomorphic branches & static `ValueType` inference: Result arms in `IF` (all 3 arguments required), `IFS`, `CHOOSE`, `IFERROR`, `IFNA` (non-`Empty` arms required), and `XLOOKUP` (`return_array` + `if_not_found`) must unify to a single scalar type (`IncompatibleBranchTypes`). `NA()` acts as polymorphic bottom (`#N/A`) for dynamic non-meaningful ratios, while formulas that evaluate to runtime `ExcelError` preserve their static `ValueType` across cell references and range slices.
  - Range-only slots, slice geometry, and lookup invariants: Syntactic `start..end` slices in scalar contexts fail with `SliceInScalarContext`; range-only slots (`COUNT`, `COUNTA`, `SUMPRODUCT`, `XLOOKUP`/`XMATCH`/`INDEX` arrays, `IRR`/`XNPV`/`XIRR` series) require `Table[...]` references (`InvalidArgumentKind`); mismatched range dimensions/lengths (`SUMPRODUCT`, `XLOOKUP`, `XNPV`, `XIRR`), 2D matrices in 1D slots (`XLOOKUP`, `XMATCH`, `XNPV`, `XIRR`), omitted `col_num` on 2D `INDEX`, constant out-of-bounds `CHOOSE`/`INDEX` indices, non-literal or wildcard (`2`) `match_mode`/`search_mode`, `Empty` `lookup_value`, heterogeneous `lookup_array`/`return_array`/`INDEX` slices, and unsorted or `Empty`/`Error`-containing binary-search arrays fail compilation with `F8Error`.
- Argument omission (`_`):
  - Intermediate optional positional parameters can be skipped via `_` when followed by at least one explicit argument (`PMT(rate, nper, pv, _, 1)`, `XLOOKUP(k, look, ret, _, -1)`, `XLOOKUP(k, look, ret, _, _, -1)`). Omitting a required parameter (`ABS(_)`, `IF(cond, t, _)`) or trailing optional parameter (`PMT(r, n, pv, _)`, `YEARFRAC(s, e, _)`) with `_` fails at compile time (`CannotOmitRequiredArgument` / `CannotOmitTrailingArgument`); omit trailing optional arguments directly (`PMT(r, n, pv)`, `YEARFRAC(s, e)`).
  - Intermediate `_` slots bind to their declared default value (or `FunctionArg::Omitted` for `XLOOKUP`'s lazy `if_not_found`, returning `#N/A` on miss); absent trailing optional arguments are not synthetically padded.
  - In lowered Excel formulas, intermediate `_` emits an empty positional argument (`=PMT(C5,C6,C7,,1)`, `=XLOOKUP(..., ..., ..., , , -1)`).
- Runtime Excel error values (returned as cell values and propagated through dependent formulas):
  - `#DIV/0!`: `x / 0`, `0 ^ -k`, `AVERAGE` on an all-empty slice, or `r = -1.0` in `NPV`.
  - `#VALUE!`: Dynamic `index_num < 1` or `> N` in `CHOOSE`, or zero `Boolean` values across sparse `AND`/`OR` range slices.
  - `#REF!`: Dynamic out-of-bounds `row_num` or `col_num` (`< 1` or exceeding slice dimensions) in `INDEX`.
  - `#NUM!`: Negative base with fractional exponent (`(-2) ^ 0.5`), `NaN`/`Inf` overflow, `MEDIAN` on an all-empty slice, `IRR`/`XIRR` with `guess <= -1.0`, `< 2` cash flows, missing sign alternation, or non-convergence, `XNPV` with `rate <= 0.0`, dates preceding the initial date (`trunc(d_i) < trunc(d_1)`) in `XNPV`/`XIRR`, `rate <= -1.0` or `nper = 0` in `PMT`/`IPMT`/`PPMT`, `per < 1` or `per > nper` in `IPMT`/`PPMT`, or `EDATE`/`EOMONTH` stepping a valid `start_date` outside `1900..=9999`.
  - `#N/A`: `NA()`, `ERROR.TYPE(value)` when `value` is not an Excel error, unmatched lookup in `XLOOKUP` (without `if_not_found`) or `XMATCH`, or no true condition in `IFS`.

## 2. Math and Aggregation Functions (12)

| Function     | Signature                      | Semantics                                                                                                                                                     |
| :----------- | :----------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ABS`        | `ABS(number)`                  | Absolute value of a `Number` scalar (`Text`, `Boolean`, and `Empty` raise `F8Error`).                                                                         |
| `SUM`        | `SUM(number1, [number2], ...)` | Sums `Number` scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` raise `F8Error`; sparse `Empty` cells in `start..end` slices contribute `0.0`; float overflow returns `#NUM!`). |
| `AVERAGE`    | `AVERAGE(number1, [number2], ...)` | Arithmetic mean across `Number` scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` raise `F8Error`; sparse `Empty` cells in `start..end` slices are skipped; returns `#DIV/0!` on all-empty slices). |
| `COUNT`      | `COUNT(value1, [value2], ...)` | Counts `Number` cells across `Table[...]` `measure` references (`descriptor` columns, `Text`, `Boolean`, and `1x1` `Empty` raise `F8Error`; ignores sparse `Empty` cells in `start..end` slices and runtime `Error` cells). |
| `COUNTA`     | `COUNTA(value1, [value2], ...)` | Counts non-empty cells across `Table[...]` `measure` or `descriptor` references (counts numbers, text including `""`, booleans, and errors; ignores `Empty`/`None`). |
| `MAX`        | `MAX(number1, [number2], ...)` | Maximum `Number` across scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` raise `F8Error`; sparse `Empty` cells in `start..end` slices are skipped, returning `0.0` on all-empty slices). |
| `MIN`        | `MIN(number1, [number2], ...)` | Minimum `Number` across scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` raise `F8Error`; sparse `Empty` cells in `start..end` slices are skipped, returning `0.0` on all-empty slices). |
| `MEDIAN`     | `MEDIAN(number1, [number2], ...)` | Median of `Number` inputs across scalars, `1x1` `measure` references, and `measure` range slices (`descriptor` columns, `Text`, `Boolean`, and scalar/`1x1` `Empty` raise `F8Error`; sparse `Empty` cells in `start..end` slices are skipped, averaging middle two on even count and returning `#NUM!` on all-empty slices). |
| `ROUND`      | `ROUND(number, num_digits)`    | Base-10 15-significant-digit commercial rounding (half-away-from-zero) of `Number` `number` to `Integer` `num_digits` decimal places (negative `num_digits` rounds left of decimal point; float overflow returns `#NUM!`; non-integer `num_digits` raises `F8Error`). |
| `ROUNDUP`    | `ROUNDUP(number, num_digits)`  | Base-10 15-significant-digit rounding of `Number` `number` away from zero to `Integer` `num_digits` decimal places (float overflow returns `#NUM!`; `F8Error` on non-integer `num_digits`).                                     |
| `ROUNDDOWN`  | `ROUNDDOWN(number, num_digits)` | Base-10 15-significant-digit truncation of `Number` `number` toward zero to `Integer` `num_digits` decimal places (`F8Error` on non-integer `num_digits`).                                     |
| `SUMPRODUCT` | `SUMPRODUCT(array1, [array2], ...)` | Element-wise product and sum across equal-dimension 1D/2D `Table[...]` `measure` ranges (`descriptor` columns, non-reference scalars, mismatched dimensions, `Text`, `Boolean`, and `1x1` `Empty` raise `F8Error`; sparse `Empty` cells in `start..end` slices contribute `0.0`; float overflow returns `#NUM!`). |

### Conditional Aggregation Composition

`SUMIFS`, `COUNTIFS`, `AVERAGEIFS`, `MINIFS`, and `MAXIFS` are intentionally omitted (`UnknownFunction`). Compose conditional aggregations explicitly with helper/flag rows or columns:

- Conditional sum: Define a helper row/column `IF(cond, value, 0)` and aggregate with `SUM(...)`, or define a `0`/`1` flag row/column `IF(cond, 1, 0)` and aggregate with `SUMPRODUCT(values, flags)`.
- Conditional count: Define a `0`/`1` flag row/column `IF(cond, 1, 0)` (combining multiple conditions via `AND(...)` / `OR(...)`) and aggregate with `SUM(flags)`.
- Conditional average: Combine `values` and `0`/`1` `flags` via `SUMPRODUCT(values, flags) / SUM(flags)` (guarding `SUM(flags) = 0` with `IF` if needed).
- Outlier-excluded `MIN` / `MAX` / `AVERAGE` / `MEDIAN`: `MIN`, `MAX`, `AVERAGE`, and `MEDIAN` skip `Empty` (`None`) cells inside `start..end` range slices—use 0D `None` overrides on excluded cells in a helper row/column when computing static subset extrema.

## 3. Logical and Branching Functions (8)

| Function  | Signature                                                                  | Semantics                                                                                                                                                    |
| :-------- | :------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `IF`      | `IF(logical_test, value_if_true, value_if_false)`                          | Short-circuiting 3-argument branch (`TooFewArguments` if `value_if_false` is omitted). `logical_test` requires `Boolean`; `value_if_true` and `value_if_false` must unify to a single scalar type (`NA()` allowed for dynamic `#N/A` suppression; referencing an `Empty` cell preserves `Empty` mid-expression for `ISBLANK`, raising `F8Error` if unguarded at the cell root). |
| `IFS`     | `IFS(logical_test1, value_if_true1, [logical_test2, value_if_true2], ...)` | Evaluates `(test, value)` pairs left-to-right with short-circuiting. Requires even argument count (`>= 2`), `Boolean` tests, and monomorphic result arms (preserving `Empty` mid-expression for `ISBLANK`). Returns `#N/A` if no condition is true. |
| `IFERROR` | `IFERROR(value, value_if_error)`                                           | Short-circuiting error trap: returns `value_if_error` only if `value` evaluates to a runtime Excel error (compile-time `F8Error`s propagate without trapping; both arms must be non-`Empty` and unify to a single scalar type). |
| `IFNA`    | `IFNA(value, value_if_na)`                                                 | Short-circuiting `#N/A` trap: returns `value_if_na` only if `value` evaluates to `#N/A`, propagating other Excel errors without evaluating `value_if_na` (both arms must be non-`Empty` and unify to a single scalar type). |
| `AND`     | `AND(logical1, [logical2], ...)`                                           | Logical conjunction across `Boolean` scalars, single-cell references, and range slices. `Number` and `Text` anywhere, and `Empty` on scalars or `1x1` single-cell references, raise `F8Error`; sparse `Empty` cells inside syntactic `start..end` slices are skipped, returning `#VALUE!` if zero `Boolean` inputs remain. |
| `OR`      | `OR(logical1, [logical2], ...)`                                            | Logical disjunction across `Boolean` scalars, single-cell references, and range slices. `Number` and `Text` anywhere, and `Empty` on scalars or `1x1` single-cell references, raise `F8Error`; sparse `Empty` cells inside syntactic `start..end` slices are skipped, returning `#VALUE!` if zero `Boolean` inputs remain. |
| `NOT`     | `NOT(logical)`                                                             | Logical negation of a `Boolean` scalar (`NOT(TRUE)` -> `FALSE`, `NOT(FALSE)` -> `TRUE`; `Number`, `Text`, and `Empty` raise `F8Error`).                      |
| `CHOOSE`  | `CHOOSE(index_num, value1, [value2], ...)`                                 | Evaluates and returns choice at 1-based `Integer` `index_num` with short-circuiting (all choice arms must unify to a single scalar type; preserves `Empty` mid-expression for `ISBLANK`). Constant out-of-bounds `index_num` raises `F8Error`; dynamic out-of-bounds `index_num` returns `#VALUE!`. |

## 4. Financial and Discounting Functions (7)

| Function | Signature                                 | Semantics                                                                                                                                                                                                                           |
| :------- | :---------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NPV`    | `NPV(rate, value1, [value2], ...)`        | Periodic net present value starting at `t = 1` (`rate` requires `Number`; `value1..` require `Number` scalars or `measure` references with no `Empty`, `Text`, or `Boolean` cells—missing periodic cash flows must be explicit `0.0`, else `F8Error`): `sum(CF_t / (1 + rate)^t)`. Returns `#DIV/0!` if `rate = -1.0` (or denominator underflows to `0.0`); `rate < -1.0` is allowed (integer exponents); float overflow returns `#NUM!`. |
| `XNPV`   | `XNPV(rate, values, dates)`               | Exact-date net present value using Actual/365 (`rate` requires `Number`; `values` and `dates` require equal-length 1D `Table[...]` `measure` ranges with `Number` cash flows in `values`, valid `DateSerial` `1.0..=2958465.0` numbers in `dates`, and no `Empty`, `Text`, or `Boolean` cells, else `F8Error`): `sum(CF_i / (1 + rate)^((d_i - d_1) / 365))`. Requires `rate > 0.0` (matching Excel's legacy `XNPV` quirk rejecting non-positive discount rates with `#NUM!` even when `-1.0 < rate <= 0.0`) and `trunc(d_i) >= trunc(d_1)` (violations return `#NUM!`). |
| `IRR`    | `IRR(values, [guess])`                    | Periodic internal rate of return via safeguarded Newton-Brent root-finding (`values` requires `Table[...]` `measure` range of `Number` cells with no `Empty`, `Text`, or `Boolean` cells, else `F8Error`; `guess` requires `Number`, default `0.10`). Returns `#NUM!` if `guess <= -1.0`, `< 2` cash flows, no sign alternation, or no real root `> -1.0`. |
| `XIRR`   | `XIRR(values, dates, [guess])`            | Exact-date internal rate of return using Actual/365 via safeguarded Newton-Brent root-finding (`values` and `dates` require equal-length 1D `Table[...]` `measure` ranges with `Number` cash flows in `values`, valid `DateSerial` `1.0..=2958465.0` numbers in `dates`, and no `Empty`, `Text`, or `Boolean` cells, else `F8Error`; `guess` requires `Number`, default `0.10`). Returns `#NUM!` if `guess <= -1.0`, `< 2` cash flows, `trunc(d_i) < trunc(d_1)`, no net sign alternation across distinct dates, or no real root `> -1.0`. |
| `PMT`    | `PMT(rate, nper, pv, [fv], [type])`       | Constant annuity payment (`rate`, `nper`, `pv`, `fv` require `Number`, `fv` default `0.0`; `type` requires `Integer` in `{0, 1}`, default `0` for end-of-period, `1` for beginning-of-period; other integers raise `F8Error`). Supports `rate = 0.0`; returns `#NUM!` if `rate <= -1.0` or `nper = 0.0`. |
| `IPMT`   | `IPMT(rate, per, nper, pv, [fv], [type])` | Interest component of annuity payment in period `per` (`rate`, `per`, `nper`, `pv`, `fv` require `Number`, `fv` default `0.0`; `type` requires `Integer` in `{0, 1}`, default `0`; other integers raise `F8Error`). Returns `0.0` when `rate = 0.0`; returns `#NUM!` if `rate <= -1.0`, `nper = 0.0`, `per < 1`, or `per > nper`. |
| `PPMT`   | `PPMT(rate, per, nper, pv, [fv], [type])` | Principal component of annuity payment in period `per` (`PMT - IPMT`; `fv` default `0.0`, `Integer` `type` in `{0, 1}`, default `0`; other integers raise `F8Error`). Returns `#NUM!` if `rate <= -1.0`, `nper = 0.0`, `per < 1`, or `per > nper`. |

## 5. Lookup and Reference Functions (3)

| Function  | Signature                                                                                        | Semantics                                                                                                                                                                                                                                                            |
| :-------- | :----------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `XLOOKUP` | `XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])` | Searches homogeneous 1D `lookup_array` (`Table[...]` required) for non-`Empty` `lookup_value` of matching type and returns corresponding element from equal-length homogeneous 1D `return_array` (monomorphic with lazy `if_not_found`; preserves `Empty` mid-expression for `ISBLANK`). Default `match_mode = 0`, `search_mode = 1`. Unmatched lookup returns `if_not_found` or `#N/A` if omitted; 2D slices, length mismatches, `Empty` `lookup_value`, or heterogeneous arrays raise `F8Error`. |
| `XMATCH`  | `XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])`                                | Returns 1-based index of non-`Empty` `lookup_value` in homogeneous 1D `lookup_array` (default `match_mode = 0`, `search_mode = 1`). Returns `#N/A` if unmatched; 2D slices, `Empty` `lookup_value`, or heterogeneous keys raise `F8Error`.                            |
| `INDEX`   | `INDEX(array, row_num, [col_num])`                                                               | Returns element at 1-based `Integer` `row_num` and `col_num` within a homogeneous 1D or 2D `Table[...]` range (preserves `Empty` mid-expression for `ISBLANK`). On 1D vectors, omitting `col_num` (or passing `1`) indexes along the vector axis; on 2D matrices, `col_num` is required (`MissingColumnIndexFor2DSlice`). Constant out-of-bounds indices raise `F8Error`; dynamic out-of-bounds indices return `#REF!`. |

### `match_mode` and `search_mode` (`XLOOKUP`, `XMATCH`)

- Literal-only modes: Both `match_mode` and `search_mode` must be integer literals when supplied (non-literal expressions, floats, or unsupported mode codes raise `F8Error`).
- `match_mode`: `0` (default) = exact match (ASCII case-insensitive for text); `-1` = exact or next smaller; `1` = exact or next larger (wildcard `match_mode = 2` is not supported).
- `search_mode`: `1` (default) = first-to-last; `-1` = last-to-first; `2` = binary search ascending (first exact match on duplicates); `-2` = binary search descending (last exact match on duplicates). Binary search modes (`2`, `-2`) require every `lookup_array` cell to be non-`Empty`, non-`Error`, homogeneous, and monotonically sorted (`F8Error` on violation).

## 6. Date and Time Functions (8)

| Function   | Signature                                 | Semantics                                                                                                                                                                                                                    |
| :--------- | :---------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATE`     | `DATE(year, month, day)`                  | Constructs Excel serial date (`1.0 <= serial <= 2958465.0`, corresponding to `1900-01-01`..`9999-12-31`) from valid calendar `Integer` `year` (`1900..=9999`), `month` (`1..=12`), and `day` (`1..=days_in_month`, preserving Excel's 1900 leap-year bug `1900-02-29` -> `60.0`; 2-digit years `0..=1899`, out-of-range years, and month/day rollovers raise `F8Error`). |
| `EDATE`    | `EDATE(start_date, months)`               | Shifts `DateSerial` `start_date` (`1.0..=2958465.0`, else `F8Error`) by `Integer` `months` calendar months, clamping end-of-month overflow to the final valid Gregorian day of the target month (`1900-02` clamps to `1900-02-28` -> `59.0`; stepping outside `1900..=9999` returns `#NUM!`). |
| `EOMONTH`  | `EOMONTH(start_date, months)`             | Returns serial date for the last Gregorian day of the month `Integer` `months` before or after `DateSerial` `start_date` (`1.0..=2958465.0`, else `F8Error`; `1900-02` returns `1900-02-28` -> `59.0`; stepping outside `1900..=9999` returns `#NUM!`). |
| `YEARFRAC` | `YEARFRAC(start_date, end_date, [basis])` | Year fraction between `DateSerial` `start_date` and `end_date` (`1.0..=2958465.0`, order-independent; truncates fractional time). Default `Integer` `basis = 0` in `0..=4` (`basis` outside `0..=4` or serial outside `1.0..=2958465.0` raises `F8Error`). |
| `YEAR`     | `YEAR(serial_number)`                     | Extracts 4-digit year (`1900..=9999`) from `DateSerial` `serial_number` (`1.0..=2958465.0`, rejecting `0` = `1900-01-00` with `F8Error`).                                                                                    |
| `MONTH`    | `MONTH(serial_number)`                    | Extracts month (`1..=12`) from `DateSerial` `serial_number` (`1.0..=2958465.0`, rejecting `0` with `F8Error`).                                                                                                               |
| `DAY`      | `DAY(serial_number)`                      | Extracts day of month (`1..=31`) from `DateSerial` `serial_number` (`1.0..=2958465.0`, rejecting `0` with `F8Error`).                                                                                                        |
| `DAYS`     | `DAYS(end_date, start_date)`              | Signed day difference `trunc(end_date) - trunc(start_date)` between `DateSerial` `end_date` and `start_date` (`1.0..=2958465.0`, else `F8Error`). Note parameter order: `end_date` first, `start_date` second.               |

### `YEARFRAC` Day-Count Basis (`0..=4`)

| `basis`          | Convention            | Denominator / Day-Count Rule                                                                 |
| :--------------- | :-------------------- | :------------------------------------------------------------------------------------------- |
| `0` (or omitted) | US (NASD) 30/360      | 30-day months / 360-day year with US end-of-February and 31st-of-month adjustment rules      |
| `1`              | Actual/Actual (AFB)   | Exact elapsed days divided by actual days in year (`365` or `366` based on leap-year rules)  |
| `2`              | Actual/360            | Exact elapsed days divided by `360.0`                                                        |
| `3`              | Actual/365            | Exact elapsed days divided by `365.0`                                                        |
| `4`              | European 30/360       | 30-day months / 360-day year where any 31st day of month is clamped to `30`                  |

## 7. Information Functions (5)

| Function     | Signature               | Semantics                                                                                                                                                                                                |
| :----------- | :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ISBLANK`    | `ISBLANK(value)`        | Returns `TRUE` if scalar `value` evaluates to `Empty` (`None` cell or reference-returning `IF`/`IFS`/`CHOOSE`/`INDEX`/`XLOOKUP` selecting an empty cell), and `FALSE` for all other values including `""` and errors. |
| `ISERROR`    | `ISERROR(value)`        | Returns `TRUE` if scalar `value` evaluates to any runtime Excel error (`#DIV/0!`, `#VALUE!`, `#REF!`, `#NAME?`, `#NUM!`, `#N/A`), and `FALSE` for `Number`, `Text`, `Boolean`, and `Empty` (compile-time `F8Error`s still fail compilation). |
| `ISNA`       | `ISNA(value)`           | Returns `TRUE` if scalar `value` evaluates to `#N/A`, and `FALSE` for all other runtime Excel errors and non-error values (compile-time `F8Error`s still fail compilation).                              |
| `ERROR.TYPE` | `ERROR.TYPE(error_val)` | Returns numeric Excel error code for runtime errors (`#DIV/0! -> 2`, `#VALUE! -> 3`, `#REF! -> 4`, `#NAME? -> 5`, `#NUM! -> 6`, `#N/A -> 7`) and `#N/A` on any non-error value (`Number`, `Text`, `Boolean`, `Empty`). |
| `NA`         | `NA()`                  | Returns `#N/A` with polymorphic bottom type, unifying with any typed branch arm (`IF(ebitda > 0, ev / ebitda, NA())`).                                                                                   |
